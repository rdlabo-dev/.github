# rdlabo Open Source

Open source software maintained by [Masahiko Sakakibara](https://rdlabo.dev/).

We build libraries and developer tools around Ionic, Angular, Capacitor, Hono, and TypeScript. Documentation for these projects is published at [docs.rdlabo.dev](https://docs.rdlabo.dev/).

## Featured projects

- [ionic-angular-library](https://github.com/rdlabo-dev/ionic-angular-library) — reusable components and utilities for Ionic Angular
- [workers-hono-kit](https://github.com/rdlabo-dev/workers-hono-kit) — shared infrastructure for Hono on Cloudflare Workers
- [ionic-theme-ios26](https://github.com/rdlabo-dev/ionic-theme-ios26) — an iOS-inspired theme for Ionic
- [ionic-theme-md3](https://github.com/rdlabo-dev/ionic-theme-md3) — a Material Design 3 theme for Ionic
- [eslint-plugin-rules](https://github.com/rdlabo-dev/eslint-plugin-rules) — ESLint rules used across rdlabo projects

Issues and pull requests are welcome. Please review the contribution and security guidance shown in each repository before submitting.
