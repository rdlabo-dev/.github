# Contributing

Thank you for contributing to rdlabo Open Source.

Before starting a substantial change, open an issue or discussion in the target repository so the scope and approach can be agreed upon. Keep pull requests focused on one concern and avoid unrelated formatting or dependency changes.

Use English for commit messages and pull request titles in public repositories.

When submitting a pull request:

1. Explain the problem and the intended behavior.
2. Add or update tests for behavior changes.
3. Run the repository's documented lint, test, and build checks.
4. Update public documentation when an API or workflow changes.
5. Do not include credentials, personal data, generated secrets, or proprietary SDK files.

Repository-specific guidance takes precedence over this default document.
