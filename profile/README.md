# rdlabo Open Source

Open source software maintained by [Masahiko Sakakibara](https://rdlabo.dev/).

We build libraries and developer tools for Ionic, Angular, Capacitor, and Cloudflare Workers. Find package guides and API references at [docs.rdlabo.dev](https://docs.rdlabo.dev/), and articles at [rdlabo.dev](https://rdlabo.dev/articles).

## Featured projects

### Ionic and Angular

- [ionic-angular-library](https://github.com/rdlabo-dev/ionic-angular-library) — application utilities, photo editing, scroll headers, and virtual scroll strategies for Ionic Angular
- [ionic-angular-collect-icons](https://github.com/rdlabo-dev/ionic-angular-collect-icons) — collect and export the ionicons used by Ionic Angular applications

### Capacitor plugins

- [capacitor-local-llm](https://github.com/rdlabo-dev/capacitor-local-llm) — on-device text generation for iOS, Android, and supported desktop Chrome
- [capacitor-printer](https://github.com/rdlabo-dev/capacitor-printer) — native printing for files and WebView content
- [capacitor-brotherprint](https://github.com/rdlabo-dev/capacitor-brotherprint) — Brother Print SDK bindings for iOS and Android

### Developer tools

- [cf-workers-native](https://github.com/rdlabo-dev/cf-workers-native) — bring Cloudflare Workers applications to iOS and Android
- [workers-hono-kit](https://github.com/rdlabo-dev/workers-hono-kit) — validation, authentication, queues, and testing helpers for Hono on Cloudflare Workers
- [eslint-plugin-rules](https://github.com/rdlabo-dev/eslint-plugin-rules) — rules for Angular, Ionic, TypeScript, and Cloudflare Workers projects
- [capacitor-docgen](https://github.com/rdlabo-dev/capacitor-docgen) — a Capacitor documentation generator with interface inheritance support

## WebView Native UI

The Ionic themes, native-control plugins for Capacitor and Cordova, and shared Engine are maintained in the [webview-native-ui](https://github.com/webview-native-ui) organization.

Their documentation is now at **[webview-native-ui.com](https://webview-native-ui.com/)**, organized as Themes, Capacitor plugins, Cordova plugins, and Developer tools. Existing WebView Native UI documentation URLs on docs.rdlabo.dev permanently redirect to the corresponding pages on the new site.

## Contributing and support

Issues and pull requests are welcome. Start in the repository that maintains the package and review its contribution, support, and security guidance. For WebView Native UI, use the relevant repository in the webview-native-ui organization.

If this work helps you, you can support its continued development through [GitHub Sponsors](https://github.com/sponsors/rdlabo).
